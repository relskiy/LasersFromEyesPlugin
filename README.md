# LasersFromEyePlugin
LabAPI-плагин, который добавляет лазеры из глаз с возможностью включения урона, редактирования визуальных эффектов.
Работает на всех человеческих классах + SCP-106, SCP-049, SCP-3114. На остальных не работает.

Лазер стреляет ровно туда, куда смотреть, при этом есть возможность включить урон.

Если посмотреть на человека, у которого в руках находится граната, то она взорвётся. Также работает с ослепительной гранатой, лампочкой.

Настраивать включение/выключение лазеров можно в Server Specific Settings.

## Команды
* ***.lasers on/off*** - включает/выключает лазеры
* ***.lasers give <player_id> <время в секундах>*** - выдаёт кому-либо лазеры только по Player ID (можно выдать на время)
* ***.lasers give all*** - выдаёт лазеры ВСЕМ игрокам, находящимся на сервере.

## Конфиг
В конфиге можно настроить:
* Ограничение доступа (по UserID и группам RemoteAdmin)
* Нанесение урона лазером
* Количество урона за тик для людей и SCP отдельно
* Интервал между тиками урона в секундах
* Причину смерти
* Логирование событий в консоль и Discord Webhook
* Детонацию взрывчатки (в руках, в воздухе, на полу и коробок с патронами)
* Радиус захвата взрывчатки вокруг луча
* Длительность анимации запуска и затухания
* Разрушение дверей и стёкол
* Следы выжигания на поверхностях и лимит их количества
* Мерцание света в комнатах от перегрузки
* Динамическое освещение (яркость и радиус в точке попадания, свет у глаз)
* Кнопку переключения в настройках клиента (ID бинда и название)
