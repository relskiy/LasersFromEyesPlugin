# LasersFromEyePlugin
LabAPI-плагин, который добавляет лазеры из глаз с возможностью включения урона, редактирования визуальных эффектов.
Работает на всех человеческих классах + SCP-106, SCP-049, SCP-3114. На остальных не работает.

Лазер стреляет ровно туда, куда смотреть, при этом есть возможность включить урон.

## Команды
* ***.lasers on/off*** - включает/выключает лазеры
* ***.lasers give <player_id>*** - выдаёт кому-либо лазеры только по Player ID
* ***.lasers give all*** - выдаёт лазеры ВСЕМ игрокам, находящимся на сервере.

## Конфиг
В конфиге можно настроить:
* Ограничение доступа
* Нанесение урона
* Количество урона за тик
* Интервал между тиками урона в секундах
* Причину смерти
* Длительность анимации включения/выключения лазеров
* Динамическое освещение (освещение от лазера)
* Интенсивность света в точке попадания
* Радиус света в точке попадания
* Интенсивность света у глаз
* Кинетический толчок физических объектов
* Силу отталкивания кинетического толчка
* Следы выжигания на поверхностях
* Мерцание света в комнатах от перегрузки
